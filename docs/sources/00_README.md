## Yang perlu kamu lakukan

1. **Unduh semua gambar** dari file Figma (https://www.figma.com/design/PacKQY9JrZzRymQGD1QcYp) sebelum link langsung kedaluwarsa.
2. **Petakan penenunmu** ke `penenun_ids` / `artisan_ids` hanya bila ada buktinya.
3. **Selaraskan proposal**: kata "pembelian" di proposal bertentangan dengan batasan "bukan marketplace" di MASTER.
4. Bidang yang paling lemah: **pewarna, lama pengerjaan, dan harga per kain.** Isi dari wawancara penenunmu.
